Scaffold

Determinate circular progress rail against the display edge, at a fixed 60%.

ArcProgressIndicator

A determinate arc along the bezel, at a fixed 60%. Remote draws it as a hairline whatever stroke width it is given — see the KDoc.

Four-page horizontal indicator curved along the bottom edge, on the first page.

PageIndicator/Vertical

LinearProgressIndicator

A straight track, for progress inside a component or a list row.

Icon

Text/Body

The Remote Material 3 text primitive, with the kit's alignment axis folded in.
×

Text/MaxLines-Truncated

maxLines=2 + ellipsis on a narrow column.
×

Text/Branded

Text in a named font family (RemoteFontFamily.Named("google:Orbitron")) rather than a generic typeface — the google: namespace marks it a Google Fonts family, which the browser lane fetches and the snapshot renderer resolves from its vendored copy.
×

Typeface/Specimen

Four branded Google Fonts families, each drawing its own name — geometric, script, grotesk, monospace. A lane that cannot resolve a named family renders four identical-looking lines.
×

Typeface/VariableWeight

One variable font (Roboto Flex) at wght 100/400/700/1000, written into the document as font-variation settings. A lane that resolves the family but drops the axes renders four lines in one weight.
×

Typeface/VariableWidth

The same variable font at wdth 25/100/151 — the axis nothing can fake, since no text API asks for a narrower face. Either the set widths differ or the axes were dropped.
×

Theme/Typography

A type ramp read from RemoteMaterialTheme.typography.
×

Theme/ColorScheme

Colour-scheme swatches read from RemoteMaterialTheme.colorScheme.
×

Theme/Specimen-ConfettiDefault

Confetti's stock theme: the unseeded Wear M3 palette over its ship pairing — Roboto Flex on title and numerals, Inter on body and label.
×

Theme/Specimen-KotlinConf

KotlinConf: JetBrains purple, with JetBrains Mono on title and numerals over an Inter body.
×

Theme/Specimen-AndroidMakers

AndroidMakers: Parisian ochre over Confetti's ship pairing.
×

Theme/Specimen-Droidcon

Droidcon: the green at full saturation, over Confetti's ship pairing.
×

Theme/Specimen-DevFest

DevFest: Google Blue with Google Sans Flex on every role — the one conference identity that swaps typography as well as colour.
×

Theme/Specimen-GoogleSansFlex

The stock Wear M3 palette with its ramp re-pointed at Google Sans Flex. Palette-identical to the Confetti baseline on purpose: this pair differs in typeface alone.
×

Theme/SystemThemeSwatches

System-theme swatches — the catalog's only document carrying ColorTheme operations, where a light and a dark colour live in the document and the player selects between them.
×

Shader/LinearGradient

Document-level gradient shader fill; the middle stop is a named value the connector can recolour live. A remote-creation-compose primitive with no Wear Material 3 component peer.
×

EdgeButton

The screen-hugging confirm action, curved to the bottom edge of the display. Remote draws the label unclipped, so it spills past the arc where the kit truncates it — see the file note.
×

CheckboxButton

A labelled row that toggles a checkbox; for a set where any number may be chosen.
×

WidgetContainer/Small

The Small (200×60dp) squircle widget container the Wear widget host draws around widget content — default surfaceContainerLow fill, 8dp padding, 26dp corners — rendered through the glance-wear WearWidgetPreview tooling wrapper.
×

WidgetContainer/Large

The Large (200×108dp) squircle widget container with the host's default background, carrying a title + supporting line.
×

WidgetContainer/GradientBackground

A Small container whose widget declares its own WearWidgetBrush background (vertical gradient) — the corner clipping over the brush is the point.
